# Description of  configuration files

The directory contains configuration files for UM_rose models. 
Each file contains definitions for 'simple' parameters. More complex parameters are done through methods in the model class.
Following files are available:

UM_rose_Parameters.csv: Definitions of parameters for both cylc7 & cylc8 configurations.
UM_rose_Parameters_c7.csv: Definitions of parameters for cylc7 configurations.
UM_rose_Parameters_c8.csv: Definitions of parameters for cylc8 configurations.
UM_rose_UKESM1_1.csv:  Definitions of parameters for UKESM1.1 model. Some will not work for earlier UM versions. 
   These were generated by ukesm_params.py
